# 2026-07-27 — PRDigest v0.3.0 release preparation

Prepared the breaking pre-1.0 release that removes deterministic digest
delivery and keeps two intentional modes: `prdigest facts` for agents and
`prdigest prose` for provider-written stdout or Telegram delivery.

The package version, changelog, local install example, packaged-gem smoke,
container smoke tag, OpenClaw source target, and release documentation now move
together at v0.3.0. The stale trusted-publishing gap was removed after v0.2.0
proved the GitHub OIDC release path.

Hive's coordinated change removes its PRDigest adapter and scheduler rather
than taking a runtime dependency on this release.
